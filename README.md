# HoloVis (Fabric 1.21.4, client-side)

Prawy Shift otwiera menu z kolumnami modułów (przeciągaj panele za nagłówek, PPM / strzałka = ustawienia, pole wyszukiwania).
**L** w menu otwiera edytor HUD (przeciągasz FPS, koordynaty i Spotify).

- **Wizualne:** Hitbox (styl, cele, wypełnienie, kolor).
- **Dźwięki:** Hit Sound / Kill Sound – wbudowane dźwięki albo własne pliki .wav.
- **Świat:** Custom Sky – kolor nieba, mgły/horyzontu i chmur (tylko Overworld).
- **HUD:** Watermark (FPS), Koordynaty, Spotify (utwór + pomijanie), Edytor HUD.
- **Klient:** Akcent GUI, Gradient, Tło GUI, Kolor napisu.

## Spotify
Mod odczytuje utwór z okna Spotify (Windows) i steruje nim klawiszami multimedialnymi.
Skróty w grze (zmienisz w Sterowanie → HoloVis): `[` poprzedni, `]` następny, `\` pauza/play.
Spotify musi być uruchomione (może być zminimalizowane, nie schowane do zasobnika).
